## NAFATH-V4 Cybersecurity Brief

This repository contains my research brief for the NAFATH-V4 Discovery Mission, Cybersecurity track.

## About the Project

I explored six areas: Software, AI, Mobile, Networking, Cybersecurity, and Data. My goal was to understand how security problems in different technologies can affect the same digital service.

I used the Log4Shell vulnerability as an example of why knowing which software libraries an application uses is important.

## Files

* brief.md – My research on the six topics, a common misconception about Log4Shell, and an open question.
* CHANGELOG.md – A summary of the work I completed.

## What I Learned

One thing I learned from this research is that cybersecurity is not just about protecting a single application. It also involves understanding the software components, data, and networks that the application depends on.
